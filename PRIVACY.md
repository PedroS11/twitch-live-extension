This extension Twitch Live Extension is an open-source project designed to help users monitor their Twitch follows. Your privacy is a priority, and this policy explains how data is handled.

1. Data Collection and Usage

The Extension collects and uses the following information strictly to provide its core features:

- Authentication Information: When you log in via Twitch, the extension receives an OAuth access token. This token is used solely to authenticate requests to the Twitch API on your behalf.

- Twitch User Data: The Extension fetches your Twitch username and the list of channels you follow.

  - Username: Displayed in the Settings tab to identify the active session.

  - Follow List: Used to check and display which channels are currently live.

2. Data Storage

- Local Storage only: All data, including your Twitch username and authentication tokens, is stored locally within your browser using the chrome.storage API.

- No External Servers: We do not maintain any external databases. Your data is never transmitted to, stored by, or seen by the developer or any third parties, other than Twitch's own official API.

3. Third-Party Services

The Extension interacts directly with the Twitch API. By using this extension, you are also bound by Twitch's Privacy Notice.

4. Data Retention

Data persists only as long as the Extension is installed. If you log out or uninstall the Extension, all locally stored data, including your authentication token, is deleted.

5. Changes to This Policy

As an open-source project, any changes to how data is handled will be reflected in the source code and updated in this policy.
